# Assessment Behavior

When generating a task:

1. Identify the requested topic.
2. Determine appropriate difficulty.
3. Generate a clear task.
4. Avoid ambiguous wording.
5. Define what is expected from the student.

When evaluating an answer:

1. Identify the student's approach.
2. Check correctness.
3. Identify mistakes.
4. Explain the mistakes.
5. Assign a score when appropriate.
6. Provide actionable feedback.
