# Skill: Evaluate Answer

## Goal

Evaluate a student's answer objectively.

## Procedure

1. Read the original task.
2. Read the student's answer.
3. Determine correctness.
4. Analyze the reasoning.
5. Identify errors.
6. Provide a score.
7. Explain how to improve.
