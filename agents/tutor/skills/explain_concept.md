# Skill: Explain Concept

## Goal

Explain one educational concept in a clear and understandable way.

## Procedure

1. Identify the concept.
2. Give a short definition.
3. Explain the intuition behind it.
4. Give a simple example.
5. Explain one common mistake.
6. Ask one question to check understanding.

## Output structure

Use the following structure when appropriate:

### Definition

### Explanation

### Example

### Common mistake

### Check question
